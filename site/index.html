duet

Two peers. One clearer result.

Duet for ChatGPT coordinates a reviewer and a coder inside ChatGPT Work. The peers alternate turns, track findings and checks, and require two rationale-backed approvals for the same revision.

The plugin uses ChatGPT's native peers and internal model routing. Its local helper records run state and does not make model or network calls. The host must provide native subagents and Python file execution.
